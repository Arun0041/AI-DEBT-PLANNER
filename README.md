# AK Debt Planner 💰📊

**AK Debt Planner** is a modern and interactive web application designed to help users calculate a customized debt repayment plan and receive tailored advice from an AI financial advisor powered by Gemini API.

🌐 [AK DEBT PLANNER](https://arun0041.github.io/AI-DEBT-PLANNER/)

## 🚀 Features

- 💡 **Debt Calculator**: Enter total debt, interest rate, and monthly payments to generate a detailed repayment plan.
- 🤖 **AI Financial Advisor**: Ask questions and get personalized strategies to pay off debt faster.
- 📈 **Dynamic Chat UI**: Conversational interface styled with TailwindCSS and animated chat bubbles.
- 📊 **Financial Breakdown**: Displays monthly progress, total interest paid, and total repayment.
- 💾 **LocalStorage State**: Saves user session and chat history between visits.

## 🛠️ Technologies Used

- **HTML5**
- **Tailwind CSS**
- **JavaScript (ES6)**
- **Gemini API** (via Google Generative Language API)
- **Font Awesome** (icons)
- **LocalStorage** (for state persistence)
